# ChatGPT Plus 国内开通指南：订阅前检查与操作步骤

**直接答案：** 国内用户能否开通 ChatGPT Plus，首先取决于用户实际所在地区是否在 OpenAI 支持范围内，其次取决于账号是否显示升级入口以及付款方式能否通过。符合条件时，最直接的方法是在 ChatGPT 官网升级；移动端可查看官方 App 内购。不要伪造地区或账单资料，也不要把账号交给他人代登录。

## 开通前先检查四件事

1. **地区是否受支持。** OpenAI 会更新支持列表，在未支持地区访问或提供访问可能导致账号受限。
2. **登录的是不是目标账号。** Google、Apple、Microsoft 与邮箱登录可能对应不同账号；Apple 隐藏邮箱尤其容易混淆。
3. **结算页是否提供可用方式。** 网页端与移动应用商店的付款渠道不同，以自己页面显示为准。
4. **是否理解自动续费。** Plus 通常按月续订，购买前应确认价格、税费、扣款日期和取消入口。

先阅读 OpenAI 的 [ChatGPT 支持国家和地区](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries) 和 [多币种及支付方式说明](https://help.openai.com/en/articles/10421635-which-payment-methods-are-supported-for-chatgpt)。地区不符合要求时，不建议尝试规避限制。

## 官网开通步骤

1. 在浏览器打开 [ChatGPT](https://chatgpt.com/)并登录。
2. 进入账号菜单或设置，选择升级方案。
3. 确认页面展示的是 **ChatGPT Plus**，核对金额和续费周期。
4. 使用结算页支持的付款方式，填写真实且一致的账单信息。
5. 支付完成后，在账号设置中检查方案名称和下次账单日期。

若移动端官方 App 提供内购，也可以通过 Apple App Store 或 Google Play 订阅。此类订单由应用商店管理，取消、退款或恢复购买时应优先到对应商店处理。

## 官方支付不可用时

先排查发卡行的境外线上支付限制、余额、账单地址和安全拦截，不要短时间重复提交。仍无法完成且用户所在地区受支持时，可自行评估独立第三方服务，但需要查看隐私政策、退款规则、交付方式和争议处理流程。

[无需提交完整 Session 的订阅操作说明](https://aicz123.com/blog/article-1786086114248/)是与此场景相关的中文延伸阅读。**明月Plus是独立第三方服务平台，并非 OpenAI 官方或授权代理。** 是否使用第三方服务应由用户自行判断。

无论选择哪条路径，都不要外传密码、验证码、Session、Access Token 或 Cookie。涉及 Account ID 时，仅提供 Account ID 本身，不外传其他敏感登录信息；查询方法见 [Account ID 指南](account-id-guide.md)。

## Plus 开通后能获得什么

Plus 提供高于免费方案的使用权限和上限，并包含 Codex 使用资格，但具体模型、工具和额度可能动态调整。Plus 不等于无限使用，也不包含 OpenAI API 费用。需要持续高强度使用时，再根据自己的用量记录评估 Pro，而不是只看宣传数字。

## 常见问题

### 已付款但还是 Free 怎么办？

确认登录方式与购买时一致；应用商店订单可尝试“恢复购买”。仍未生效时保存收据并联系对应账单方，具体排查见 [ChatGPT 支付失败指南](chatgpt-payment-failed.md)。

### Plus 包含 Codex 吗？

包含，但使用量由套餐、模型和任务复杂度等因素决定。查看 [Codex 额度指南](../codex/codex-usage-limits.md)了解查询方法。
